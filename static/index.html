Your personal receiver is ready. Proxmox will send failed backup notifications here, and we'll forward them to your Telegram.

1. In Proxmox open
Datacenter → Notifications → Targets → Add → Webhook
2. Method
POST
3. Webhook URL
4. Header
Content-Type: application/json
5. Body
{ "title": "{{ title }}", "message": "{{ message }}", "severity": "{{ severity }}", "type": "{{ fields.type }}", "hostname": "{{ fields.hostname }}", "timestamp": "{{ timestamp }}" }
